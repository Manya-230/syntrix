# Syntrix – Product Requirements Document (PRD)

Version: 1.0

---

## Product Vision

Syntrix is the professional networking platform for the music industry.

It helps DJs, producers, vocalists, instrumentalists, organizers, venues, studios, photographers, videographers, labels, and music professionals connect, collaborate, discover opportunities, and grow their careers.

---

## Problem Statement

Today, music professionals struggle to:

- Find collaborators nearby
- Discover gigs
- Network professionally
- Build a portfolio
- Find event organizers
- Hire creatives
- Discover studios
- Communicate professionally

Most networking happens through Instagram DMs, WhatsApp groups, and word of mouth.

Syntrix brings everything into one platform.

---

## Mission

Build the operating system for the independent music industry.

## Core Value Proposition

Syntrix helps music professionals discover nearby collaborators, showcase their work, find gigs, join events, and build meaningful industry connections through one dedicated platform.

---

## Minimum Viable Product (MVP)

The first version of Syntrix will include:

### Authentication
- Email sign up
- Google sign up
- Login
- Password reset

### User Profiles
- Profile photo
- Cover photo
- Artist name
- Bio
- Genres
- Skills
- Location
- Social links
- Portfolio

### Explore
- Search users
- Filter by role
- Filter by genre
- Filter by city

### Connections
- Send requests
- Accept requests
- View network

### Feed
- Create posts
- Like
- Comment

### Messaging
- One-to-one chat
- Real-time messaging

### Gig Board
- Create gigs
- Apply to gigs
- Save gigs

### Events
- Create events
- RSVP
- View attendees
